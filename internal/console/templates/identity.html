This tenant's key

Everything this tenant seals (the sign-in secret, notification endpoints, the mail-signing key, the device-signing key) is sealed under a key that is this tenant's alone. Rotating it makes a new one and re-seals those values; no other tenant is touched. {{if .Identity.KeyVersion}}Current: version {{.Identity.KeyVersion}}{{if .Identity.KeyCreatedAt}}, since {{.Identity.KeyCreatedAt.Format "2 Jan 2006"}}{{end}}.{{else}}Not yet made: it is made the first time something is sealed.{{end}}

Export everything

Every record this tenant has, as one zip of JSON lines per table, for leaving or for keeping. Sealed secrets, token hashes and one-time codes are not in it. Making one is recorded in the audit log.

Download the export

Or send it straight to your own storage. Any S3-compatible bucket takes it: AWS S3, Cloudflare R2, MinIO, Backblaze B2, Wasabi. The keys you type here are used for this one upload and are not kept, not logged and not in the audit line, which names the bucket and the file.

Move to another region

A move bundle carries everything, sealed values included, for the region you are moving to. The key below comes from that region's operator; it never leaves this page and is not kept. Making a bundle is recorded in the audit log. After the import there, this tenant is offboarded here.

Network integrations

Your Wi-Fi controller, VPN or NAC asks this console whether a device may be let on, with a token you mint here. The answer is allow or deny: deny for a device that is quarantined or retired, and for one that has not reported clean in the last seven days. A token can read that and nothing else. It is shown once.
